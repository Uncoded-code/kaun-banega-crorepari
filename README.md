# F1 KBC Quiz

A simple terminal quiz inspired by Kaun Banega Crorepati (KBC). Answer 15 multiple choice questions about Formula 1 and work your way up the prize ladder.

## Features

- 15 Formula 1 trivia questions
- Four answer choices for each question
- A prize ladder that increases as you play
- The game ends when you enter an incorrect answer

## Requirements

- Python 3.6 or newer

## How to Run

Open a terminal in the project folder and run:

```bash
python kbc.py
On Windows, you can also run:
py kbc.py
How to Play
Each question shows four choices: A, B, C, and D. Enter the corresponding number:
- 1 for A
- 2 for B
- 3 for C
- 4 for D
Answer correctly to continue to the next question.
Note
The game prompt mentions entering 0 to quit, but the current code treats 0 as an incorrect answer.
